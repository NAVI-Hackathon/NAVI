# NAVI · 兩分鐘展示

「法國巴黎人壽智慧服務導航：理解情況、整理下一步、帶到服務入口。」

預設 $0：`npm run dev:all`，使用 README 的 `/embed?mode=demo` 設定；未設定嵌入時開 `http://127.0.0.1:5173/demo`。3000 是模擬官網、5173 是 NAVI、3001 是 API。不要啟動 Live 或宣稱本次使用真實 Gemini。

| 時間 | 操作 | 結果 |
| --- | --- | --- |
| 0:00–0:15 | 在模擬官網 `/services/claims` 展示原本的服務分頁，開啟右下角 NAVI | 使用者不用自己找文件與入口 |
| 0:15–0:30 | 「我上週在台中榮總住院五天，要怎麼申請理賠？」 | 住院醫療旅程 35%，辨識合作院所；不判斷資格 |
| 0:30–0:55 | 使用範例診斷書／住院證明 | 70%，整理醫院、病患與五天住院期間；明確為 Mock |
| 0:55–1:15 | 使用範例存摺 | 90%，只顯示帳號末四碼；點「帶我去」查看匯款文件規則 |
| 1:15–1:35 | 確認資料與保險金申請書 | 100%；從 READY_FOR_REVIEW 進 READY_TO_PROCEED |
| 1:35–1:50 | 前往服務預覽，再導覽至醫起通說明 | 模擬官網換頁／分頁並高亮，不連正式平台、不送件 |
| 1:50–2:00 | 問「密碼輸錯被鎖住」「受益人變更申請書在哪下載」 | 知識答案、來源與可信「帶我去」 |

100% 僅代表原型定義的資料準備完成，不代表保障適用、理賠通過、已申請或已核付。條件性文件依病況提供；本原型以匯款給付示範存摺需求。醫起通合作名單、聯盟鏈正本提醒、郵寄與匯款資料均來自本地官網整理資料，不是即時官方確認。

補充展示：未知需求補充說明、低信心專員摘要、移除文件撤回準備度與確認、重新開始示範、同分頁 reload。非合作院所只引導查看聯盟鏈或郵寄管道條件，不判斷是否可使用或是否給付。

Backend 已提供住院 Journey 與文件 pipeline，但目前 UI 文件／workflow 仍是 A 的本地 Adapter；不可把前端 Mock 當成真實辨識。Backend Gemini transport 僅經注入假回應驗證，最新本地測試見 `backend-hospitalization.md`。班機延誤與車禍保留 Legacy tests，不列為比賽展示業務。
