## 流程

| 時間 | 操作 | 畫面結果 | 講稿重點 |
| --- | --- | --- | --- |
| 0:00–0:20 | 在模擬官網開「保戶服務 → 理賠程序介紹」，切換幾個分頁 | 官網資訊分散在多頁、多個分頁與表格 | 痛點：保戶得自己找功能、讀完說明才知道要準備什麼 |
| 0:20–0:30 | 點右下角 **NAVI** | 助手在官網內開啟，不用離開頁面 | NAVI 整合在官網裡，不是另一個網站 |
| **一、什麼都能問** | | | |
| 0:30–0:55 | 輸入「受益人變更表單在哪下載」 | 答案卡片「受益人變更申請書」＋官網來源與擷取日期 | 答案只引用官網公開資料，每張卡片附來源 |
| 0:55–1:05 | 點「帶我去：下載受益人變更申請書」 | 官網自動換到「常用表單下載」，捲到該列並高亮 | **不只回答，還帶到功能入口**（題目要求的「找到功能入口」） |
| 1:05–1:20 | 在 NAVI 按「重新描述」，輸入「密碼輸錯被鎖住了」 | 常見問題：錯誤 5 次鎖定帳號，需打客服解鎖 | 常見問題直接回答 |
| 1:20–1:35 | 輸入「我只有門診開刀，沒有住院，要怎麼申請理賠？」 | 「醫療門診理賠應備文件」，不會誤進住院流程 | 能處理口語和「沒有住院」這類否定說法 |
| **二、護欄** | | | |
| 1:35–1:45 | 輸入「推薦我買哪張保單」 | 「這個問題需要由專人協助」＋客服專線 | 不給投保建議、不判斷能否理賠，不會編造答案 |
| **三、住院理賠完整旅程** | | | |
| 1:45–2:00 | 輸入「我上週在台中榮總住院五天，要怎麼申請理賠？」 | 住院醫療理賠旅程 **35%**；辨識臺中榮民總醫院為醫起通合作醫院 | 從一句話建立服務旅程：要準備什麼、走哪個管道 |
| 2:00–2:15 | 點「使用範例文件」（診斷書） | **70%**；醫院、住院期間 5 天；標示「示範辨識資料，未讀取文件內容」 | 文件辨識在示範模式使用合成資料 |
| 2:15–2:25 | 點「帶我去：查看匯款給付規定」 | 官網捲到「匯款給付需提供存摺影本」並高亮（窄螢幕時 NAVI 會自動收合） | 每一步都能回到官網原文 |
| 2:25–2:40 | 回到 NAVI（若已收合，點右下角），上傳範例存摺 | **90%**，帳號只顯示末四碼 | 個資最小化：瀏覽器只存案件編號 |
| 2:40–2:55 | 確認資料（勾選兩項）→ 前往服務 | **100%**；建議醫起通並列出注意事項 | 100% 只代表資料準備完成，不代表理賠核准或已送件 |
| 2:55–3:00 | 結語 | | 「找得到、看得懂、帶得到」：降低搜尋成本，帶到正確入口 |

**兩分鐘版**：省略 1:05–1:35 的兩題（密碼、門診），以及 2:25–2:40 的存摺，直接從 70% 講到確認流程。

## 一定要講清楚的事

- 100% 只代表原型定義的資料準備完成，**不代表保障適用、理賠通過、已申請或已核付**。
- 醫起通合作名單、聯盟鏈正本提醒、應備文件都來自團隊整理的官網公開資料（擷取日期 2026-10-06），不是即時官方確認。
- 示範模式的文件辨識是合成資料，畫面已標示；不要說成 AI 實際讀了文件。
- 模擬官網是團隊重建的示範網站，頁尾標註「InsurHack 模擬網站，非官方」。

## 備用題（評審追問時）

| 輸入 | 結果 |
| --- | --- |
| 保單借款多久撥款 | 審核無誤後約 5–7 個工作天，免手續費 |
| 家人過世不知道有沒有保險 | 「戶政連線‧理賠免奔波」：辦死亡登記時同時申請 |
| 癌症理賠需要哪些文件 | 「防癌或重疾理賠應備文件」（「癌症」對應官網用語「防癌」） |
| 我在榮總住院五天（沒說哪一家） | 不猜院所：建議聯盟鏈或郵寄，並請提供醫院全名 |
| 住院旅程中，在「AI 助手」問「線上申請還要寄正本嗎？」 | 挑出官網原文：10 日內須寄回正本；超過 30 萬元需等正本寄達 |
| 今天天氣如何 | 「我還需要一些資訊」，不硬湊答案 |
| 我搬家了，保單上的地址要怎麼改？ | 「變更戶籍地址／收費地址」**（資料檔「線上辦理」欄位有一句內部筆記，修正前不要用）** |

## 出狀況時

| 狀況 | 處理 |
| --- | --- |
| NAVI 顯示「這份服務旅程已失效」 | 正常：後端重啟或超過 1 小時，重新描述即可 |
| 「分析服務暫時無法使用」或 API 無回應 | 改開 http://207.148.113.119:8080/demo，流程相同 |
| VPS 整個連不上 | 改用本機 `npm run dev:all` |
| 評審問「有用 AI 嗎」 | 後端已串接 Gemini 做意圖理解與文件辨識（限免費方案、有成本保護）；免費方案曾回應逾時，所以展示用示範模式，確保穩定、零成本。知識問答一律只引用官網資料，不讓 AI 生成答案 |
