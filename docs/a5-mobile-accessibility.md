本次修正：
- **NAVI**：導覽卡「結束導覽」、來源面板「開啟官網原頁」、文件健檢「依病況可能需要」、提示訊息的關閉鈕都放大到 36 px；導覽卡裡夾在句中的來源連結也加大了可點範圍，但行高不變。輸入框取得焦點時改成清楚的綠色外框。
- **模擬官網**：頁尾連結、麵包屑、頁首登入與 logo、表單「下載」按鈕都放大到 36 px。段落中的文字連結依 WCAG 屬於例外，不調整。

既有、已確認無需修改：對話框會鎖住焦點、可用 Escape 關閉並把焦點還回原按鈕；對話串是 `role="log"` 並設定 `aria-live`；導覽每一步的內容會自動唸出；準備度圓環有 `progressbar` 標籤；Enter 送出、Shift+Enter 換行，輸入中文選字時按 Enter 不會送出。

## 2. 無法自動驗證的限制

- Chromium 模擬不等於 iOS Safari：鍵盤彈出時畫面高度怎麼變化、捲動回彈、`visualViewport`、iframe 內的 Cookie，都要實機確認。
- VoiceOver 的實際朗讀順序與內容，沒有用輔助技術實測。
- iOS「文字大小」設定通常不會影響網頁；網頁放大以 Safari「aA → 放大」為準，自動測試只用 320 寬代表放大後的重排。

## 3. iPhone Safari 實機清單（Sh 實測後填寫）

裝置／iOS 版本：＿＿＿＿　日期：＿＿＿＿　網址：https://navitw.com/?navi=demo 與 https://navitw.com/

| # | 步驟 | 預期 | 結果 |
| --- | --- | --- | --- |
| 1 | 開 `https://navitw.com/?navi=demo`，按右下角 NAVI | 全螢幕開啟、最上方有「示範」標示 | |
| 2 | 點輸入框 | 鍵盤彈出後輸入框仍在鍵盤正上方，看得到最新訊息 | |
| 3 | 打「理賠要準備什麼文件」→ 送出 → 點「醫療門診」 | 先追問，再出現門診答案；可展開來源 | |
| 4 | 收起鍵盤，捲動對話到最上面再到最下面 | 只有對話區捲動，輸入框固定在底部 | |
| 5 | 打「我搬家了，保單地址要怎麼改？」→ 點「帶我去」 | NAVI 收起，官網換頁並框出位置；右下按鈕變成「回到 NAVI・繼續下一步」 | |
| 6 | 點「回到 NAVI」→「下一步」，走完 3 步 →「完成導覽」 | 每一步官網都跟著換頁並框出位置；導覽卡不蓋住輸入框 | |
| 7 | 打住院描述 →「開啟工作區」→ 用範例文件到 70／90 → 確認資料 | 100% 顯示「資料初步準備完成・尚未送件」 | |
| 8 | 「需要協助？轉由專員接續」→ 勾選 → 確認 | 顯示「尚未送出」；對話框可以捲到底 | |
| 9 | Safari「aA」把網頁放大到 150% 再操作 3、5 | 文字不被切掉、不必左右捲動 | |
| 10 | 開 VoiceOver，聽歡迎訊息、選項按鈕、準備度、導覽卡 | 按鈕都唸得出名稱；準備度唸出數字 | |
| 11 | 開一般模式 `https://navitw.com/`，按 NAVI 打住院描述 | Live 分析成功，或顯示清楚的錯誤（例如額度用完）並提供示範模式網址 | |
